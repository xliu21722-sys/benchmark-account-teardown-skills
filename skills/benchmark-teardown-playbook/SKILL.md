# 对标拆解方法论：AI 短视频怎么拍

## 适用范围

**适用**：AI 赛道短视频的标题、选题、互动、系列、更新节奏、商单。
**不适用**：平台后台数据分析（完播率、流量来源）；公众号长文、直播；代用户登录或批量抓取。
**拆解对标账号、出报告或规律汇总** → 用 `benchmark-crawl-teardown`。

## 核心原则

1. **做出来给人看**：视频结束时，观众要能亲眼看到一个用 AI 做出来的真东西，而不是听你讲 AI 有多厉害。
2. **爆款用相对口径**：点赞 ≥ 本号中位数 3 倍才算爆款，大小号才可比。
3. **时长走两极**：≤3 分钟讲透一个点，或 ≥20 分钟讲透一件事；5–10 分钟两头不靠。
4. **单条爆款不等于涨粉**：涨粉靠持续出爆款和可追更的系列。
5. **结论都带样本量**：样本小、靠单个号撑起来的只当线索。

**拍前三道坎**：做得出东西吗 → 讲一个点还是一件事 → 这条主要图什么互动。
**观众三问**：和我有关吗 / 能马上看懂吗 / 看完能拿走什么。
**选题从哪来**：评论区和私信里的问题；自己亲手做成功过、但多数人还没做过的事。

> 下文百分比是 AI 赛道 2026 年 8–10 月的样本参考值，不是平台规则。换赛道或隔了几个月，先用 `benchmark-crawl-teardown` 在自己的对标号上重测；有对标规律汇总时，以汇总数据为准。

## 一、起标题与避雷

**规则**
- 爆款标题三式，底层意思都是「播完能看到一个做出来的东西」：
  1. 这条视频本身就是 AI 做的；
  2. 不会写代码的我，用 AI 做出了 X；
  3. 从 0 到 1，手把手把 X 做出来。
- 高收藏标题：「完整版 / 全教程 / 从 0 到 1 / 讲透」（参考爆款率 39%）；清单「数字 + 明确范围（+ 建议收藏）」（37%）。
- 避雷：「X 分钟学会 / 讲清」（8%，像标题党）；「实测 / 测评 / 横评 / 对比」（12%）；「刚刚发布 / 突发」式快讯（≈平均，拼不过新闻大号）。

**步骤**
1. 确认成品是什么；没有成品就先把选题改成「做出来给人看」。
2. 三式各写 1 个；清单或完整教程再加写对应写法。
3. 逐条避雷，命中就改写。
4. 有对标规律汇总时，用汇总里「标题写法」表的爆款率给每个标题标依据。
5. 输出 3–5 个标题，每个注明用的哪一式、避雷结果。

**示例**：选题「用 Claude 做记账小程序」→ ①「这个记账 App 从代码到界面都是 Claude 写的」②「不会写代码的我，用 Claude 做了个记账 App」③「从 0 到 1，手把手用 Claude 做一个记账 App」；不写「10 分钟学会做 App」。

**注意**：「不会写代码的我」必须属实；标题不能承诺视频里没有的成品。

## 二、新模型发布拍什么

**规则**：不测评、不抢快讯，用新模型真正新增的能力做出一个好玩或有用的作品。测评赛道最卷（参考爆款率 12–13%，观众刷到第五条就分不清谁是谁）；快讯只有平均水平。

**步骤**
1. 读官方发布说明，列出 1–2 个真正新增的能力。
2. 每个能力想一个普通人一眼看懂的作品：小工具、动画、成片、自动化流程。
3. 选一个 1–2 天内能做出来的。
4. 标题用三式之一，不出现「实测 / 测评 / 对比」。
5. 输出：作品方案 + 标题 + 预计时长。

**注意**：定位本来就是评测号的，不强行转型，建议「测评里必须有一个做出来的作品」作为差异化；作品依赖的能力要亲测可用，不拿官方 demo 冒充。

## 三、互动目标与系列化（爆了为什么不涨粉）

**规则**
- 三种互动来自三种视频：**转发**靠好玩猎奇；**收藏**靠有用、能照做（清单、手把手）；**评论**靠鲜明观点。
- 互动高低和涨粉速度对不上，只说明观众拿这条视频当什么用。涨粉靠两样：持续出爆款（参考：30 天 0 爆款的号多数在掉粉，≥3 条的基本不掉）+ 有延续感、能追更的系列。
- 实测佐证：一个号的系列第 15 期 280 倍、续集第 16 期 105 倍，续集吃到了追更。

**步骤**
1. 问清这条视频的主目标，只选一个。
2. 按目标给形式：转发 → 好玩可视；收藏 → 清单 / 手把手；评论 → 鲜明观点；涨粉 → 系列。
3. 系列设计：固定命名（第 N 天 / 第 N 期 / 本周 XX）+ 每期一个看得见的成果 + 片尾预告下一期 + 标题带期数。
4. 有对标数据时，比较系列号和非系列号的涨粉（第二次采集后才有涨粉数据，没有就如实说）。

**注意**：系列不能凑期数；评论驱动不靠恐吓焦虑。

## 四、更新节奏、发布时间、商单

**规则**
- **节奏**：可以慢更，不能断更。底线是每 30 天至少 4 条（参考：30 天 0–1 条的号基本在掉粉）；慢更号的平时点赞反而高于高频号，拼数量补不上质量。
- **发布时间**：各时段差别很小，不用纠结；除非用户自己账号有 ≥200 条的时段数据。
- **商单**：不当硬广拍，把金主的工具当素材，拍成「用它做出 X 效果」的实战教程，可以不掉流甚至成爆款。

**步骤**
1. 节奏：给出「30 天 ≥4 条」的底线，其余按能保证质量的节奏定。
2. 时间：不做时段优化，除非有足够的自有数据。
3. 商单：把产品改写成「用它做出 X 效果」的教程选题，确认视频里有看得见的成果；硬广脚本直接提示风险。

**注意**：频率和数据只是相关，可能是「好内容本来就慢」；商单结论样本很少；按平台规范标注商业合作。

## 通用边界

- 相关不等于因果；对标号是挑出来的，有选样偏差。
- 相对口径对平时点赞很低的小号更宽松。
- 题材风向变得很快，几个月前的热门题材必须重测。
- 恐吓、末日类内容互动高，但换不来信任，不推荐。
- 超出以上四类的问题，明确告知不在本方法论范围内，不硬套。
